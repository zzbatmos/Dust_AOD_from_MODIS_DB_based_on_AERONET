# Sensitivity artifacts (not the product)

The earlier `old675LR56` reference and the `minimal2` feature fallback remain
separately identified sensitivities. They are not loaded by the v2 product
predictor and must not silently substitute for its primary artifacts.

The original inference binaries and checksum inventories are retained here
under explicitly labeled reference directories. They are not installed in the
product wheel. Full training-membership lists remain preserved in private
analysis storage for the pending archive. An approved archive identifier will
be recorded before publication. No release DOI is assigned by this working branch.
