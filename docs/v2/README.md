# DBDust v2 documentation

This directory holds the documentation for the v2 release of the MODIS Deep
Blue dust AOD estimator.

- `FREEZE_V2_SPEC.md`: specification and instructions for producing the frozen
  v2.0.0 release (code, configuration, model artifacts, outputs and tests).
- Files to be added by the release work: `ALGORITHM.md`, `MODEL_CARD.md`,
  `DATA_FORMAT.md`, `FREEZE_REPORT.md`.

The v1.0.0 method (tag `v1.0.0`) remains unchanged in the repository root.
